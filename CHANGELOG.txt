  fix: root UUID TOCTOU in get_file_content (F-1)
    findmnt -no UUID / was called on every get_file_content invocation
    for /etc/kernel/cmdline, creating a TOCTOU between install_file's
    comparison and write paths. UUID is now cached once in _load_profile
    as _ROOT_UUID global. get_file_content uses the cached value.
  feat: _kconfig_cache lazy loader for /proc/config.gz (F-2)
    _ntsync_state and _validate_kernel_params both called zcat on
    /proc/config.gz independently. New _kconfig_cache function reads
    once on first call, stores in _KCONFIG_DATA global, returns cached
    lines on subsequent calls. Both consumers updated.
  fix: boot-critical short-circuit in do_install (F-3)
    When _install_rebuild_boot returned EXIT_BOOT_CRIT, do_install
    continued to _install_collect_wifi and _install_finalize, masking
    the failure with unrelated errors and prompting for WiFi credentials
    unnecessarily. Now short-circuits: skips WiFi/finalize, emits
    actionable error, calls _progress_skip for remaining steps to keep
    counter synchronized.
  feat: hardware mismatch early warning in _load_profile (F-4)
    Hardcoded gtr9_pro fallback would silently apply GTR9 Pro kernel
    params on a different machine. _load_profile now checks /proc/cpuinfo
    against EXPECTED_CPU_MATCH (if set) and warns with profile switch
    guidance. Lightweight — no lspci/sudo; full fingerprint check remains
    in _install_preflight.
  feat: flock(1) atomic lock reclaim in _acquire_lock (F-5)
    Stale lock reclaim via rmdir+mkdir had a documented TOCTOU race
    window. When flock(1) is available, stale reclaim now acquires an
    advisory lock on the parent directory, making the rmdir+mkdir+write
    sequence atomic. Falls back to original PID-re-verify approach when
    flock is absent. flock -n -E 5 provides non-blocking contention
    detection.
